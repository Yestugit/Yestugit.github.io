最近我开发了一个叫 [PixivCrawler](https://github.com/Yestugit/PixivCrawler) 的小工具，用来把自己在 Pixiv 上能够正常查看的作品下载到本地，方便分类、备份和长期归档。

它不是一个需要自己配置脚本和 Cookie 的命令行程序，而是面向 Windows 10/11 x64 的桌面应用。登录、筛选、预览、下载和查看任务进度都可以直接在图形界面中完成。目前最新版本是 **v0.2.2**。

> PixivCrawler 只访问当前登录账号本来就有权查看的内容，不会绕过登录、验证码、年龄、地区或作品权限限制。下载内容仅适合个人本地归档，请尊重作者版权、Pixiv 服务条款和所在地法律。

## 为什么做这个工具

平时在 Pixiv 收藏作品很方便，但收藏数量变多以后，想按作者、标签或作品类型整理就比较麻烦。如果只是逐张右键保存，多图作品、漫画和动图的处理也不够顺手；网络中断后还可能需要重新下载。

因此我想做一个更适合个人归档的工具：既能批量获取作品，又能控制请求节奏；不仅保存图片，还保留作品的基本信息；遇到暂停、退出或临时网络错误时，也尽量能够接着之前的进度继续。

## 四种下载方式

PixivCrawler 目前提供四种下载入口：

1. **作品链接**：粘贴一个或多个作品链接或作品 ID，适合精确下载指定作品。
2. **搜索作品**：输入主题、标签、中文译名或 Pixiv 标签页链接，从搜索结果中筛选作品。
3. **作者作品**：输入作者主页链接或作者 ID，批量归档该作者的作品。
4. **我的收藏**：归档当前账号的公开收藏、非公开收藏，或者两者一起归档。

主题搜索支持设置最低收藏数、浏览数和点赞数，并可以限制最终下载的图片数量，范围是 1–100 张。为避免无节制地请求站点，热度筛选最多检查 500 个候选作品。

搜索顺序有三种策略：

- **跨时间均衡**：从新、中、旧不同时间段收集候选，比较适合配合热度条件寻找作品。
- **最新优先**：从最近发布的作品开始检查。
- **最旧优先**：从较早发布的作品开始检查。

对于“莉可丽丝”这样的中文译名，如果它能够精确匹配 Pixiv 的官方标签候选，工具会自动改用对应的主标签进行搜索。

## 筛选与作品类型

创建任务时，可以先预览匹配的作品数和图片数，再决定是否开始下载。筛选条件包括：

- 插画、漫画和 ugoira 动图；
- 发布日期范围；
- 必须包含或需要排除的标签；
- 是否包含 AI 作品；
- 全部、全年龄或仅 R-18 / R-18G；
- 收藏的公开状态。

普通插画和漫画会保存原图。对于 ugoira，工具会保留原始 ZIP 和帧时序 JSON，同时生成便于播放的 MP4 文件。

## 下载过程与任务恢复

下载任务可以暂停、继续、取消，也可以对失败任务重新尝试。应用会保存搜索解析进度、已经匹配的作品、已完成页面和 `.part` 文件的字节位置，所以暂停任务或重启应用以后，不必总是从零开始。

图片会先写入 `.part` 临时文件，下载完成后再原子改名。临时网络错误、HTTP 429 或服务器 5xx 错误会自动重试；遇到站点限流时，程序会按照 `Retry-After` 进行全局冷却。默认最多同时处理 4 个请求，并且每 500 毫秒才启动一个新请求，也可以在设置中降低并发或放慢请求间隔。

登录使用应用内部独立的 Chromium 会话，不读取外部浏览器 Cookie。Cookie 只保存在这个持久化会话中，不会复制到界面或 SQLite 数据库。

## 文件会保存在哪里

默认下载目录是：

```text
图片/PixivCrawler/{作者名}_{作者ID}/{标题}_{作品ID}/
```

图片文件名格式为：

```text
{作品ID}_p{页码}.{扩展名}
```

每个作品目录还会保存一份 `artwork.json`，其中包含标题、作者、标签、发布时间、作品类型和来源链接等归档信息。任务记录与去重信息则保存在 SQLite 中。

安装版的应用数据默认位于 `%LOCALAPPDATA%/PixivCrawler`。ZIP 便携版会把数据放在程序旁的 `data` 目录，更适合放在移动硬盘或独立文件夹中使用。下载根目录也可以在设置页面自行修改。

## 下载与使用

可以直接下载已经打包好的 Windows x64 版本：

- [下载安装版 v0.2.2](https://github.com/Yestugit/PixivCrawler/releases/download/v0.2.2/PixivCrawler-0.2.2-x64.exe)
- [下载免安装版 v0.2.2](https://github.com/Yestugit/PixivCrawler/releases/download/v0.2.2/PixivCrawler-0.2.2-x64.zip)
- [查看全部 Releases](https://github.com/Yestugit/PixivCrawler/releases)

第一次使用的大致流程是：

1. 打开应用，点击左下角的“登录”。
2. 在独立窗口中完成 Pixiv 登录、验证码或两步验证。
3. 选择作品链接、搜索作品、作者作品或我的收藏。
4. 设置需要的筛选条件并预览结果。
5. 创建任务，等待下载和整理完成。

如果 Pixiv 的访问需要代理，设置页面也支持系统代理以及自定义 HTTP、HTTPS 或 SOCKS5 代理。

## 技术实现

PixivCrawler 使用 Electron、React 和 TypeScript 开发，使用 SQLite 保存任务状态和去重记录，并通过 FFmpeg 将 ugoira 转换为 MP4。项目提供单元测试和端到端测试，Windows 版本会打包为 NSIS 安装程序和 ZIP 便携包。

如果想从源码运行，需要 Node.js 22 或更高版本：

```powershell
git clone https://github.com/Yestugit/PixivCrawler.git
cd PixivCrawler
npm install
npm run fetch:ffmpeg
npm run dev
```

Pixiv 使用的站点 AJAX 接口并不是稳定的公开 API，未来页面或响应结构变化时，工具可能需要继续适配。项目会尽量把这类问题明确显示为适配器错误，而不是悄悄生成不完整的归档。

## 写在最后

PixivCrawler 的目标不是追求无限并发或尽可能快地抓取，而是做一个使用简单、能够恢复、方便整理，并且对站点请求相对克制的个人归档工具。

项目目前以 MIT 许可证开源。如果你也有本地整理 Pixiv 作品的需求，可以前往 [GitHub 项目主页](https://github.com/Yestugit/PixivCrawler) 查看源码、下载最新版本或反馈问题。
